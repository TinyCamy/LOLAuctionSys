# LOL内战

一个使用 Flask 和 SQLite 构建的英雄联盟内战比赛管理工具。玩家可以创建或加入比赛房间、完成队长与队员选择，并由房主逐局录入 KDA 和比赛结果。

## 已实现功能

- 玩家账户：使用手机号注册和登录；首次密码默认为游戏 ID；可在个人中心维护段位、主玩位置与最多两个备选位置。
- 比赛房间：创建人可设置比赛名称、系统生成的比赛 ID、赛制、偶数人数、队长选择方式、队员选择方式、拍卖资金、段位调整和可选房间密码。
- 房间管理：房主可删除未结束的比赛；其他玩家可退出房间；支持快捷按比赛 ID 加入、虚拟队员补满房间，以及首页查看已参加的比赛。
- 队长产生：支持指定、推举和随机三种方式；启用“根据段位调整拍卖金额”时，队长每相差一个段位，基础资金提高 10%。
- 队员选择：支持掷骰顺序选人，以及双队长密封拍卖；支持同价流拍后重排、队长资金展示、剩余资金限制和完整选人记录。
- 赛果录入：房主可按比赛顺序录入 A/B 队胜负及每位玩家的击杀、死亡、助攻；满足赛制胜场后自动结束，所有参赛者均可查看历史成绩，房主可在编辑模式调整每一局记录。

## 技术栈

- Python 3.10+
- Flask 3
- SQLite（本地文件数据库）
- 原生 HTML、CSS、JavaScript

## 本地运行

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

启动后访问 <http://127.0.0.1:5000>。首次运行会自动创建本地数据库文件 `lol_auction.db`。

## 测试

```powershell
python -m unittest discover -s tests -v
```

## 数据与安全说明

- `lol_auction.db` 存放本地玩家和比赛数据，不会提交到 Git 仓库。
- 上传目录 `static/uploads/` 也不会提交；当前比赛结果无需上传截图。
- 开发环境的 `SECRET_KEY` 有默认值。部署到生产环境前，请设置随机且保密的 `SECRET_KEY` 环境变量。

## 目录结构

```text
app.py               Flask 路由、业务逻辑和数据库初始化
templates/           页面模板与比赛流程界面
static/              样式与拍卖区域的前端交互
tests/               自动化测试
requirements.txt     Python 依赖
```
